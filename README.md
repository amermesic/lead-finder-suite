# Lead Finder Suite

## Overview
Lead Finder Suite is a Python-based web crawling and lead generation tool designed for agency prospect discovery workflows.

The system supports lead search, data extraction, enrichment, deduplication, and structured export into JSON/CSV formats.

## Tech Stack
- Python
- JSON
- Requests
- BeautifulSoup (if used)
- Selenium (if used)

## Core Features
- Lead Search module
- LinkedIn scraping workflow
- Domain & email crawling
- Data enrichment (phone/social discovery)
- Deduplication engine
- Structured JSON export
- Outreach preparation tools

## Architecture
Modular Python-based system with separated crawling, processing, and export logic.

## Data Output
- JSON export
- Optional CSV export
- Cleaned and deduplicated lead lists

## Setup
1. Clone the repository
2. Create a virtual environment
3. Install dependencies via requirements.txt
4. Run the main script (mu_client_finder.py)

## Disclaimer
This repository does not contain any private client data, credentials, or API keys.
